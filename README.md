# 🧼 Dirty Customer Sales – Autonomous SQL Project

## 📍 Project Overview

This is a fully self-directed SQL project built from a raw, unstructured sales dataset — with **no business questions or prompts provided**. The objective? **Simulate a real-world analyst scenario** where critical thinking, initiative, and business framing are the only tools you have.

I assumed full ownership of the problem, transforming messy data into a **strategic business intelligence framework** focused on:

- 💰 Revenue generation
- 💸 Refund impact analysis
- 📈 Sales performance tracking by employee and region
- 📊 Future sales projections (positive and negative drift)
- 🧠 Governance-minded logic and structural data redesign
